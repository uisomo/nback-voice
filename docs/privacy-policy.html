プライバシーポリシー（音声N-back）

最終更新日: 2026年8月30日

本アプリ「音声N-back」（以下「本アプリ」）における利用者情報の取り扱いについて説明します。

収集する情報

  • マイク音声・音声認識結果 — 回答方法として「音声」を選んだ場合のみ。認識結果はテキストとして扱われ、音声データそのものは保存されません。
  • 回答テキストと問題文 — 採点のために、入力または認識された回答と対応する問題文を後述の外部APIに送信します。
  • アプリ内の学習データ — シリーズごとの難易度（N）、成績履歴、自作した問題・デッキ、学習済みの別解表現。すべて端末内（AsyncStorage）に保存され、外部サーバーには送信されません。
  • APIキー — 設定画面で入力したAnthropic APIキーは端末内にのみ保存されます。

第三者への情報提供

回答の採点（正解・不正解の判定）には Anthropic 社の Claude API を使用しています。 採点のたびに、その回答に対応する問題文と回答テキストが Anthropic 社のサーバーに送信されます。 送信されるのはテキストのみで、氏名・連絡先などの個人を特定する情報は含みません。 Anthropic 社によるデータの取り扱いについては、 Anthropic プライバシーポリシー をご確認ください。

APIキーをご自身で設定画面に入力される場合、採点リクエストはお客様ご自身のAnthropicアカウントの利用枠として処理されます。

サブスクリプション（アプリ内課金）

本アプリは Apple の App Store を通じた自動更新サブスクリプションを提供しています。 決済処理はすべて Apple の StoreKit を通じて行われ、クレジットカード情報など決済情報そのものが本アプリや開発者に渡ることはありません。 購入情報の確認（本人の正当な購入であることの検証）は端末上で Apple の署名を検証する方式で行っており、外部サーバーへの送信は行っていません。

データの削除

本アプリを削除（アンインストール）すると、端末内に保存されたすべてのデータ（成績履歴、自作問題、設定、APIキー）が削除されます。
